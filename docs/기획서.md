# 💘 병맛 연애 시뮬레이션 기획서

> **"사랑은 타이밍, 근데 내 타이밍은 고장남"**

| 항목 | 내용 |
|---|---|
| 장르 | 텍스트 선택형 연애 시뮬레이션 (병맛 코미디) |
| 플랫폼 | Windows PC (Python 3 / tkinter) |
| 플레이 시간 | 1회 약 3~5분 (10개 챕터, 즉사하면 더 짧음) |
| 난이도 | 지옥 🔥 (아무렇게나 고르면 TRUE 엔딩 확률 10% 미만) |
| 대상 | 가볍게 웃고 싶은 대학생 |
| 개발 | AI융합소프트웨어과 1학년 개인 프로젝트 |

---

## 1. 기획 의도

- 진지한 연애 시뮬레이션의 **클리셰(첫 만남, 첫 카톡, 고백)**를 그대로 가져온 뒤 **엉뚱한 선택지와 반전 대사**로 비틀어 웃음을 주는 게임이다.
- 목표는 "설렘"이 아니라 **"웃김"이 1순위**. 진지한 대사가 나오면 반드시 반전을 준다.
- 짧은 플레이 + 랜덤 요소로 **여러 번 다시 해서 엔딩을 모으고 싶게** 만든다.

## 2. 핵심 재미 요소

| 요소 | 설명 |
|---|---|
| 병맛 선택지 | "책 대신 학생증 건네기", "PPT 30장으로 고백" 같은 말도 안 되는 선택지 |
| 랜덤 호감도 | 일부 선택지는 점수가 범위 안에서 랜덤 → 같은 선택도 결과가 다름 |
| 선택지 셔플 | 매 장면마다 선택지 순서가 섞여서 외워서 깨기 어려움 |
| 히든 엔딩 | 비둘기 관련 선택(이벤트 포함)을 4번 이상 하면 '비둘기와의 사랑' 엔딩 |
| ⏰ 5초 제한 | 선택지를 5초 안에 못 고르면 '읽씹' 처리되어 호감도 -15 |
| 💀 즉사 선택지 | 고르는 순간 즉사 엔딩 (전 애인과 번호 교환, 시험지 유출, 다단계 권유 등 4개) |
| ⚡ 돌발 이벤트 | 챕터 사이에 35% 확률로 비, 비둘기 습격, 새똥, 단톡방 박제 등 6종 발생 |
| 🎨 캐릭터 그림 | 호감도에 따라 표정이 바뀜 (하트 눈 / 폭포 눈물), 비둘기 게이지가 있으면 머리 위에 비둘기 |
| 이름 커스텀 | 상대 이름을 마음대로 바꿀 수 있고, 조사(이/가, 은/는)가 자동으로 맞춰짐 |

## 5. 시스템 규칙

- **호감도**: 10에서 시작 (지옥 난이도). 화면 위쪽에 막대 그래프로 표시 (60 이상 분홍, 30 이상 노랑, 그 아래 파랑)
- **비둘기 게이지**: `PIGEON` 태그 선택지(Chapter 1, 3, 5, 6, 9)나 비둘기 습격 이벤트로 +1
- **제한 시간**: 장면마다 5초 타이머 막대. 시간 초과 시 호감도 -15
- **엔딩 판정** (위에서부터 먼저 맞는 것)

| 조건 | 엔딩 |
|---|---|
| 즉사 선택지 | 💀 즉사: 게임 오버 |
| 비둘기 게이지 ≥ 4 | 🐦 히든: 비둘기와의 사랑 |
| 호감도 ≥ 100 | 💖 TRUE: 우리 사귀는 거 맞지? |
| 호감도 ≥ 60 | 💛 노멀: 썸의 무한루프 |
| 호감도 ≥ 30 | 💚 친구: 넌 좋은 사람이야 |
| 호감도 ≥ 0 | 💙 읽씹: 1이 사라지지 않아 |
| 호감도 < 0 | 🚨 배드: 차단당했습니다 |

## 6. 기술 구성

| 항목 | 내용 |
|---|---|
| 언어 | Python 3 (3.14에서 테스트) |
| GUI | tkinter (파이썬 기본 내장) |
| 외부 라이브러리 | 없음 (파이썬 기본 모듈만 사용) |
| 그래픽 | `images/`에 PNG가 있으면 PNG, 없으면 tkinter Canvas로 그린 캐릭터 |
| 배포 | PyInstaller로 `byungmat_love.exe` 단일 실행파일 |
| 테스트 | `unittest` 33개 (조사, 엔딩, 장면 데이터, 난이도, 이벤트, 그림, 타이머, GUI 레이아웃) |

**구조 설계**: 대사·선택지 같은 **데이터(`SCENES`)**와 화면을 그리는 **로직(`LoveGame`)**을 분리했다.
데이터는 연극 대본, `LoveGame`은 대본을 연기하는 배우와 같아서 **새 챕터는 `SCENES`에 딕셔너리만 추가**하면 된다.
