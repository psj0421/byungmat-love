# 💘 병맛 연애 시뮬레이션 기획서

> **"사랑은 타이밍, 근데 내 타이밍은 고장남"**

| 항목 | 내용 |
|---|---|
| 장르 | 텍스트 선택형 연애 시뮬레이션 (병맛 코미디) |
| 플랫폼 | Windows PC (Python 3 / tkinter) |
| 플레이 시간 | 1회 약 2~3분 (6개 챕터) |
| 대상 | 가볍게 웃고 싶은 대학생 |
| 개발 | AI융합소프트웨어과 1학년 개인 프로젝트 |

---

## 1. 기획 의도

- 진지한 연애 시뮬레이션의 **클리셰(첫 만남, 첫 카톡, 고백)**를 그대로 가져온 뒤 **엉뚱한 선택지와 반전 대사**로 비틀어 웃음을 주는 게임이다.
- 목표는 "설렘"이 아니라 **"웃김"이 1순위**. 진지한 대사가 나오면 반드시 반전을 준다.
- 짧은 플레이 + 랜덤 요소로 **여러 번 다시 해서 엔딩을 모으고 싶게** 만든다.

## 2. 핵심 재미 요소

| 요소 | 설명 |
|---|---|
| 병맛 선택지 | "책 대신 학생증 건네기", "PPT 30장으로 고백" 같은 말도 안 되는 선택지 |
| 랜덤 호감도 | 일부 선택지는 점수가 범위 안에서 랜덤 → 같은 선택도 결과가 다름 |
| 선택지 셔플 | 매 장면마다 선택지 순서가 섞여서 외워서 깨기 어려움 |
| 히든 엔딩 | 비둘기 관련 선택을 3번 이상 하면 '비둘기와의 사랑' 엔딩 |
| 이름 커스텀 | 상대 이름을 마음대로 바꿀 수 있고, 조사(이/가, 은/는)가 자동으로 맞춰짐 |

## 3. 캐릭터

| 성별 | 이름 | 특징 | Chapter 5 질문 |
|---|---|---|---|
| 남 | 🧔 김철수 | 3대 500이 인생 목표인 헬스광. 닭가슴살을 반려동물처럼 아낌 | "너... 닭가슴살 좋아해?" |
| 여 | 👩 이영희 | 민트초코 광신도. 반민초파 이름을 수첩에 적음 | "너... 민트초코 좋아해?" |

## 4. 게임 흐름

```
시작 화면 (상대 성별·이름 선택)
   ↓
Chapter 1 ~ 6  ──선택──▶  반응 화면 (호감도 변화 표시)  ──▶ 다음 Chapter
   ↓ (6장 끝)
엔딩 화면 ──▶ 다시 하기 / 종료
```

| 챕터 | 제목 | 상황 |
|---|---|---|
| 1 | 📚 운명적인 첫 만남 | 도서관에서 『연애하는 법 for Dummies』를 떨어뜨림 |
| 2 | 📱 첫 카톡 | "뭐해?"라는 세상에서 가장 어려운 질문 |
| 3 | 🗺️ 첫 데이트 장소 | 파스타집 / 다이소 / 할머니 댁 / 비둘기 공원 |
| 4 | 🍽️ 밥값 계산의 시간 | 계산서 앞의 정적 |
| 5 | 💥 돌발 상황 | 상대의 취향(닭가슴살/민트초코) 검증 |
| 6 | 💌 운명의 고백 | 벚꽃(사실 낙엽) 아래 고백 |

## 5. 시스템 규칙

- **호감도**: 30에서 시작. 화면 위쪽에 막대 그래프로 표시 (60 이상 분홍, 30 이상 노랑, 그 아래 파랑)
- **비둘기 게이지**: `PIGEON` 태그 선택지를 고르면 +1 (Chapter 1, 3, 5에 하나씩)
- **엔딩 판정** (위에서부터 먼저 맞는 것)

| 조건 | 엔딩 |
|---|---|
| 비둘기 게이지 ≥ 3 | 🐦 히든: 비둘기와의 사랑 |
| 호감도 ≥ 80 | 💖 TRUE: 우리 사귀는 거 맞지? |
| 호감도 ≥ 50 | 💛 노멀: 썸의 무한루프 |
| 호감도 ≥ 20 | 💚 친구: 넌 좋은 사람이야 |
| 호감도 ≥ 0 | 💙 읽씹: 1이 사라지지 않아 |
| 호감도 < 0 | 🚨 배드: 차단당했습니다 |

## 6. 기술 구성

| 항목 | 내용 |
|---|---|
| 언어 | Python 3 (3.14에서 테스트) |
| GUI | tkinter (파이썬 기본 내장) |
| 외부 라이브러리 | 없음 (`tkinter`, `random`만 사용) |
| 배포 | PyInstaller로 `byungmat_love.exe` 단일 실행파일 |
| 테스트 | `unittest` 16개 (조사 처리, 엔딩 경계값, 장면 데이터, GUI 레이아웃) |

**구조 설계**: 대사·선택지 같은 **데이터(`SCENES`)**와 화면을 그리는 **로직(`LoveGame`)**을 분리했다.
데이터는 연극 대본, `LoveGame`은 대본을 연기하는 배우와 같아서 **새 챕터는 `SCENES`에 딕셔너리만 추가**하면 된다.
