캐릭터 이미지 넣는 곳
====================

이 폴더에 아래 이름으로 PNG를 넣으면 게임에서 그 그림이 나와요.
파일이 없으면 코드로 그린 얼굴(Canvas)이 대신 나와요. 일부만 넣어도 돼요.

  male_normal.png    male_happy.png    male_sad.png      (김철수)
  female_normal.png  female_happy.png  female_sad.png    (이영희)

- normal: 평소 / happy: 호감도 올랐을 때 / sad: 호감도 떨어졌을 때
- 정사각형, 130x130 근처 크기가 제일 깔끔해요 (크면 자동으로 정수배로 줄여요)
- 형식은 PNG만 돼요 (JPG는 tkinter가 못 읽어요)
- 저작권 주의: 연예인 사진, 다른 게임/웹툰 캐릭터 그림은 쓰면 안 돼요.
  직접 그린 그림이나 상업적 이용이 허락된 AI 생성 이미지를 쓰세요.
- 이미지를 넣은 뒤 build_exe.bat를 다시 실행해야 exe에도 들어가요.
